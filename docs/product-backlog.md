# Tobytube Product Backlog

## Animation randomizer customization

Future enhancement for the Animation-only continuous randomizer:

- Let the user choose which television series are eligible.
- Let the user include or exclude individual seasons within each eligible series.
- Let the user choose which movies are eligible when the Movies toggle is enabled.
- Preserve the current playback contract: continuous random playback until the user exits, with no more than one movie per ten television episodes.
- Persist the user's selections so a customized pool survives subsequent sessions.
